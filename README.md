# 🧠 Diabetes Prediction System

This is a Machine Learning based web application that predicts whether a person has diabetes based on medical inputs.

## 🚀 Features

- Machine Learning Model (Random Forest)
- Data Preprocessing & Scaling
- Flask Web Application
- User-friendly UI with validation
- Landing Page + Prediction Page

## 🛠 Tech Stack

- Python
- Flask
- Scikit-learn
- HTML/CSS (Bootstrap)

## 📊 Model Details

- Logistic Regression (Baseline)
- Random Forest (Final Model)
- Accuracy: ~76%
- Focus on Recall (Medical Use Case)

## ▶️ How to Run

```bash
pip install -r requirements.txt
python app.py
